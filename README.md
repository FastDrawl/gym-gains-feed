# gym-gains-feed

Public gains feed for Ryan's Gym Gains widget.

`gym_data.json` is regenerated daily from his Gravl workout history
(workouts, per-exercise top-weight gains, XP and trophies) and served
via GitHub Pages at:

https://fastdrawl.github.io/gym-gains-feed/gym_data.json

The file contains only aggregated workout statistics — no tokens,
credentials, or secrets anywhere in this repo.
